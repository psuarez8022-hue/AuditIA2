# Instalación del proyecto AuditIA 2.0

## Herramientas utilizadas

- Google AI Studio
- Supabase
- GitHub

## Configuración

1. Crear un proyecto en Google AI Studio.
2. Crear una base de datos en Supabase.
3. Crear la tabla auditia_documentos.
4. Configurar el repositorio en GitHub.

## Evidencias

- Generación de documentos mediante Gemini.
- Almacenamiento de información en Supabase.
- Control y documentación del proyecto mediante GitHub.
