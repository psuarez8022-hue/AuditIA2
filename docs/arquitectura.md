# Arquitectura de AuditIA 2.0

## Flujo funcional

1. El auditor identifica la necesidad de elaborar un documento.
2. El usuario formula un prompt en Google AI Studio.
3. Gemini genera el documento solicitado.
4. La información relevante se registra en Supabase.
5. GitHub almacena la documentación técnica y el control de versiones del proyecto.

## Componentes

### Google AI Studio

Motor de Inteligencia Artificial.

### Supabase

Base de datos para almacenar solicitudes y respuestas.

### GitHub

Repositorio del proyecto y documentación técnica.
